# meghann
Personal website made with react and golang

# Quickstart
### Start Everything
1. (from root) `make dev`

### Running Server
1. `cd backend/`
2. `go run main.go`

### Running Frontend
1. `npm run dev`

### Other Commands
- `make deploy`
-  (from /frontend) `npm run deploy`
- (from /frontend) `npm run format`
